# ✈️ Airplane Detection with YOLOv8

Lightweight computer vision project for airplane detection and tracking in video using YOLOv8.

The notebook runs in a Kaggle environment. To use it with your own video, simply update the video path to the file you want to process.

The pipeline processes the video, detects airplanes, tracks their movement across frames, and generates an annotated output video.

The example shown uses footage of an F-16 as a demonstration sample.
