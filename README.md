# Airplane Tracking with YOLOv8

[![Python](https://img.shields.io/badge/Python-3-3776AB?logo=python)](https://python.org/)
[![YOLOv8](https://img.shields.io/badge/YOLOv8-latest-00C853?logo=ultralytics)](https://ultralytics.com/)
[![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-F37626?logo=jupyter)](https://jupyter.org/)

Real-time airplane detection and tracking in video using YOLOv8 object detection and computer vision techniques. Features bounding box visualization, movement tracking across frames, and confidence-based detection filtering.

## Features

- **Object detection** — YOLOv8 model for accurate airplane identification
- **Frame-by-frame tracking** — continuous detection across video sequences
- **Bounding box visualization** — labeled detection boxes with confidence scores
- **Movement tracking** — follow airplane trajectories across frames
- **Confidence filtering** — configurable detection threshold for accuracy tuning
- **Notebook-based workflow** — fully documented in a Kaggle-compatible Jupyter notebook

## Tech Stack

- **Python 3** — Core programming language
- **Ultralytics YOLOv8** — State-of-the-art object detection model
- **OpenCV** — Video processing and frame manipulation
- **Jupyter Notebook** — Interactive development environment
